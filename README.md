# Wand Core

Releases of Wand Core (terminal service, structured conversation service, gateway, updater and web client) for macOS and Linux. Source is private; this repository holds the signed releases and their build workflow. Every Core archive includes sessiond, agentd, gatewayd and updater at the same version and build; the services retain independent lifecycles.

Install: `curl -fsSL https://wandapp.github.io/install.sh | sh`

More at https://wandapp.github.io
